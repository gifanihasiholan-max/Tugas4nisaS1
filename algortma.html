Apa Itu Algoritma

Algoritma adalah langkah-langkah sistematis untuk menyelesaikan suatu masalah.
Sebelum membuat program, programer sebaiknya memahami masalah dan solusi yang akan dibuat.

Langkah Membuat Algoritma

  1. Memahami masalah
  2. Menentukan input
  3. Menentukan proses
  4. Menentukan output
  5. Menulis langkah penyelesaian
  6. Menguji solusi

Struktur Dasar Algoritma

  • Sequence
  • Selecation
  • Iteration

Contoh Struktur

  • Sequence
    • Input
    • Process
    • Output
  • Selecation
    • IF
    • IF ELSE
    • SWITCH
  • Interation
    • FOR
    • WHILE
    • DO WHILE

Istilah Algoritma

Input
Data yang dimasukan ke dalam program.
Process
Tahapan pengolahan data.
Output
Hasil yang diberikan oleh program.
Flowchart
Diagram yang digunakan untuk menggambarkan alur algoritma.

Contoh Algoritma Sederhana

  1. Masukan nilai pertama
  2. Masukan nilai kedua
  3. Jumlahkan kedua nilai
  4. Tampilkan hasil
Algoritma yang baik harus jelas,logis,dan sistematis.

Berpikir sebelum coding! Jangan langsung menulis kode sebelum memahami masalah.
