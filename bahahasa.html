Mengenal Bahasa Pemprogaman

Bahasa pemerogaman digunakan untuk memberikan instruksi kepada komputer. setiap bahasa mempunyai karakteristik dan kegunaan yang berbeda.
seorang pemerogaman sebaiknya memahami konsep pemerogaman,bukan hanya menghafal sintaks.


Contoh Bahasa Pemerogaman

  2. Java
  3. JavaScript
  4. PHP
  5. C++
  6. Dart

Istilah bahahasa pemerogaman

Syntax
Aturan penulis code dalam sebuah bahasa pemprogaman.
Variable
Tempat untuk menyampaikan sebuah nilai atau data.
Function
Kumpulan intruksi yang dapat dipanggil untuk melakukan tugas tertentu.
Library
Kumpulan kode yang dapat digunakan kembali dalam program.
